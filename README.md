# Gerador de mapas de The Binding of Isaac (modificado)

Gerador de andares no estilo de **The Binding of Isaac: Rebirth** usado no trabalho de Algoritmos em Grafos, feito em Unity (C#). Cada mapa gerado é exportado em JSON para virar um grafo: as salas são os vértices e as portas são as arestas, com o custo da porta como peso.

## Projeto original

Este projeto é uma versão modificada do **The Binding of Isaac Map Generator**, de Garnet (GarnetKane99):

- Código original: https://github.com/GarnetKane99/Binding-Of-Isaac_Map-Generator

Todo o crédito pela geração do mapa vai para o autor original.

Este projeto é só um trabalho acadêmico, sem fins comerciais.
